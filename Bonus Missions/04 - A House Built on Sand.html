Before you start — four facts that shape every run

One starting location, no mastery gates. This bonus mission has a single start point and no mastery track, so no loadout or start is locked behind a level. Sources name the start differently (Consulate Plaza / outside the city gates); all agree there is only one.

One Agency Pickup. A single large stash on the rooftops, reached by the pipe near the side gates. Anything you want up high has to be sent there.

No security cameras. The "destroy the evidence" clause on the Classics is free here, which is why No Evidence isn't a challenge on this map.

Seven disguises. Bodyguard, Military Soldier, Fortune Teller, Waiter, Handyman, Food Vendor, Shopkeeper. That is the full set for Chameleon.

Save-scumming is required here — and it is the main risk

Each target can only die once per run, and this mission has eleven separate kill challenges. The plan below uses one save per run to farm several kills from one setup. That is unavoidable, but loading a save is also the most common reason a Hitman challenge silently fails to register. If something won't pop after two honest tries, restart the mission and go straight for it with no loads.

Run logic checks

  • Every challenge is assigned. 35 of 35 appear in a run; Discover Marrakesh is assigned to Run 0 with an explanation of why it cannot be earned inside this mission.
  • Items before use. Run 2 collects the wrench from the rooftop stash before the escort begins, not after. Run 4 collects the utility room key, screwdriver and both outfits before its save point. Run 6 collects the crowbar and truck key before the exit save.
  • Disguises before they are needed. Bodyguard is taken before the rifle in Run 5, before the escort in Run 2. Waiter is taken before any VIP sabotage in Run 4.
  • NPCs preserved. Run 4 never touches the handyman at the phone booth — he has to walk away on his own for Phony Call to work. Run 3 sends the fortune teller's customer away instead of killing her.
  • Targets stay alive until their challenges are done. Waiting For the Man is never scheduled after a run that kills Mendola. The Future Foretold is isolated in Run 3 for the same reason.
  • Mutually exclusive kills separated. License to Ill, Laughing Gas and Escort Service all resolve the same meeting, so Run 2 splits them across one save. Run 4 pairs one Mendola kill with one Kong kill per pass, so four kills take two passes instead of four.
  • Exits separated. Only one exit can be used per run, so Truck Off, Break Out and Sneaking Away sit behind a single save at the end of Run 6.
  • Versatile spread. Only two targets exist per run, so the five Versatile kills are split: poison and drowning in Run 1, fiber wire and headshot in Run 2, accident in Run 4.
  • No dead ends. No step in any run removes an NPC, item or scripted event that a later step in the same run depends on.

Still unverified — insufficient evidence from available sources

  • XP values. Only one is documented: Discover Marrakesh is +1000 XP. No other per-challenge value is claimed anywhere in this guide.
  • NPC names. Only the two targets are named by the game. "Boyle", the bodyguard who wandered off carpet shopping, comes from one walkthrough's transcription of an overheard conversation. Every other NPC is described by role and position.
  • Whether drowning also counts as an accident. It probably does, but no source confirms it for this mission, so Someone Could Hurt Themselves is assigned to the oil lamp explosion in Run 4, which is unambiguously an accident.
  • Electric Boogie's bug history. One source states it was unobtainable at launch and fixed in the Season of Pride update on 6 May 2021. Single source.
  • Whether the meeting rooftop and the carpet shop rooftop are the same roof. Guides describe the meeting as a rented rooftop patio next to the shisha café and place the carpet-shopping bodyguard on the carpet shop roof. Rooftop Rendezvous specifically names the carpet shop, so the guide sends you there deliberately rather than assuming the escort covers it.
  • Whether a wrench can be found on the map. One guide marks a wrench near the café, but not precisely enough to direct you to it, so Run 2 smuggles one instead.
  • Re-equipping your suit for Chameleon. One player reports the starting suit counting toward Chameleon. The seven listed disguises are the documented requirement; changing back at the end costs nothing.
