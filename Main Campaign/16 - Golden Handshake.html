Why 55 and not 56. The v8.7.0 challenge data lists 56 entries for this mission. Read this before you start

Reloading a save can stop a challenge from registering. This is the most common cause of a "bugged" challenge in the series and is widely reported. If something you clearly did doesn't pop, restart the mission and go straight for it without touching a save. Every SAVE HERE badge is a convenience, not a guarantee.

There is no "Hero of New York" challenge. The old "complete 3 mission stories" challenge and "No Evidence" were both cut in HITMAN III. The five mission stories each have their own separate challenge now and can be done in any order relative to each other.

Every Savalas kill method is mutually exclusive within a run. One target, one death per attempt. Save immediately before the kill, take one method, reload, take the next.

Verified totals

55 challenges: 11 Assassination, 18 Discovery, 20 Feats, 1 Targets, 5 The Classics. Total 96,000 XP, one unlock (the Golden Sawed-Off Bartoli 12G).

Checked three ways. The category counts come from the Hitman Wiki table; your uploaded in-game JSON matches it name-for-name and description-for-description; and the individual XP values sum independently to exactly 96,000 (24,000 + 23,000 + 25,000 + 4,000 + 20,000). A missing or invented entry would break that sum. The JSON's UI_PEACOCK… and LOCATION_PARENT_GREEDY strings are server placeholders for the escalation-support slot, not a real 56th challenge.

Cut & changed

  • Cut in HITMAN III: "Mission Stories – The Milton-Fitzpatrick Bank" (do 3 stories) and "No Evidence".
  • Added in HITMAN III: the individual The Job Interview and On and Off Again story challenges.
  • Moved category: Chameleon, Seven Figures and You're Hired! → Discovery; Brute Force, Expediter 47 and Ocean's 47 → Feats.
  • The Great Thief added post-launch (one source: 30 Apr 2024; exact patch unconfirmed).

Mutually exclusive within one run

  • Every Savalas kill method — one target, one death per attempt. Save-scum (Run 2).
  • The three exfiltrations — you leave once. Superintendent (R1), Executive (R2), Heavy (R3).
  • The Cronkite files — one set: Ruby Red (Whistleblower/Exposé/Insider Trading) OR the conference room (Mirror kill trigger). Use the laptop reschedule for the mirror so both fit in Run 4.
  • The vodka bottle — shared between A Drink to Die For and the Frank challenge. Separate reloads.
  • Hard Core vs any rating — carrying the core makes everyone an enforcer. Stash it or skip it on Run 6.
  • Peeping Tom before The Applicant — Mr. Thomas must still be conscious and being sick.

Known bugs — confirmed vs unconfirmed

Confirmed (historical): at the map's June 2019 launch, players who'd fully explored the bank couldn't re-trigger Discover Milton-Fitzpatrick. IO acknowledged it and patched it. Long resolved.

Confirmed (engine-wide): loading a save can stop a challenge registering. Restart and take it fresh if one won't pop.

Not confirmed: no verified Golden Handshake-specific scripting conflict between mission stories. The five stories are independent and need no fixed order. If a guide claims otherwise, I couldn't source it.
