Run-logic validation (simulated step by step)

  • 55 of 58 challenges are assigned. The three left out are Heeeere's Johnny, Chameleon and Discover Bangkok — see above.
  • Prerequisites precede use. Run 1 takes the master keycard before the Camberwell lounge; Run 3 takes the cake topper before the birthday room and the master keycard before the kitchen; Run 4 breaches room 207 before it needs anything inside it; Run 5 takes Dexy's safe combination before the safe.
  • Nothing needed later is destroyed earlier. Every branch that kills a target sits behind a save and reloads, except the last one in each run. Run 1 keeps the balcony push, Run 3 keeps the cake smother, Run 4 keeps the microphone, Run 5 keeps the exploding phone.
  • Un-spotted requirements are isolated. Run 1 carries Basement Jack at the very start; Run 5 carries Hide and Don't Seek and Rubber Duck Sunday, which are at opposite ends of that run with a lot of cover between them.
  • Ordering hazards are respected. Run 4 delays picking up the microphone because of a known script bug, and delays the room-207 sniping until security has removed the body.
  • The Classics capstone lands last. Run 6 delivers Sniper Assassin; Run 7 delivers Silent Assassin, Silent Assassin Suit Only and Suit Only, and the capstone fires when Run 7 completes.

Known conflicts, bugs and ordering rules

  • Run 2, coconut RNG. fish reports a bug where the second set of coconuts can vanish as they fall. Save at the shooting position and reload until all three land. The two nearest trees are also the only ones that do not kill an NPC when their coconuts drop.
  • Run 4, do not take the microphone early. There is a bug where Mission Story — Are 'Friends' Electric will not start if you are already carrying the microphone. Start the story first, collect the microphone afterwards.
  • Run 5, do not sit down too early. Jordan leaves the room instead of talking if you are already seated behind the room divider when he enters. Wait until he is in and talking to himself before sitting.
  • Run 5, the phone kill is tight. His guards enter shortly after the explosion, so the body has to be hidden and you have to be in his bathroom almost immediately. Expect several attempts.
  • Run 1, stay close to Ken during the escort. If you fall behind he decides you are taking too long and resumes his normal route. It is recoverable — talk to him again — but it costs a minute.
  • Cameras: the north wing and the basement are covered densely and there is only one recorder, in the second-floor security office of the north building, guarded by three people. NamuWiki's advice is to shoot cameras with a silenced pistol rather than hunt the recorder, which is what the SASO run does.
  • Difficulty: the branch-and-reload structure assumes unlimited manual saves, i.e. Casual. The Classic challenges are no longer difficulty-tiered in World of Assassination.
