Run-logic validation (simulated step by step)

  • 76 of 80 challenges are assigned. The four left out are The Bells are Ringing, Get What You Wish For, Chameleon and Discover Sapienza — see the table above.
  • Prerequisites precede use. Run 1 takes the biolab keycard before the lab, the priest before the church, the flowers before the grave; Run 4 takes the explosive golf ball out of the safe house before crossing to the mansion; Run 9 collects both joints and the crowbar before it needs any of them.
  • The virus is handled every run. Every run that is not Run 1 ends with "destroy the virus and exit" — the mission cannot be completed without it, and an unfinished mission banks nothing that requires completion.
  • Keycard shortcut. After Run 1, fish notes that Francesca drops a biolab keycard when she dies, so later runs never repeat the morgue sequence.
  • Mutually exclusive kills are separated. Silvio has fourteen distinct kill challenges and Francesca eight. Every run that stacks more than one puts a save between them, and the branch that is kept is always the last one in its section.
  • No-detection challenges are isolated. Runs 1, 3 and 4 each carry one (Weeding the Garden, Getting Your Hands Dirty, Pipe Down / BBQ Season) and none of them shares a run with a different one — except Run 4, where Pipe Down and BBQ Season are both un-spotted requirements but are separated by a save.
  • The Classics capstone lands last. Run 8 delivers Sniper Assassin; Run 10 delivers Silent Assassin, Silent Assassin Suit Only and Suit Only, and the capstone fires when Run 10 completes.

Known conflicts, bugs and ordering rules

  • BBQ Season only works on one fireplace. The challenge text does not say so, but fish confirms it: the propane-down-the-chimney kill in Run 2 does not score BBQ Season. It must be the specific mansion fireplace on Silvio's patrol route in Run 4.
  • Run 4, the lure needs the fan. After ringing the service bell in Mother Caruso's bedroom you must also switch on the fan by the rocking chair, or Silvio flees instead of entering.
  • Run 1, cook the sauce prompt. In Run 3 the prompt has to actually read "cook sauce" before the spaghetti can be poisoned; interacting too early does nothing.
  • Run 5, poison the champagne early. Save while Francesca is still outside the room and not too close to the door, or there is not enough time to spike the glass before she reaches it.
  • Run 7, the plane shot. Fire the last cannon when the escape timer reads about 00:20 and the plane is centred on screen. It is the tightest single input in the whole mission.
  • Run 8, red guns are fine. Bodies being found turns the guards hostile, but at church-tower range they only get a shot-location alert. Sniper Assassin survives as long as you are never actually compromised.
  • Difficulty: the branch-and-reload structure assumes unlimited manual saves, i.e. Casual. The Classic challenges are no longer difficulty-tiered in World of Assassination.
