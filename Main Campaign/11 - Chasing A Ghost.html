How to read this

Each step is laid out the same way — GO (where), DISGUISE, ITEM, NPC, DO (the action) — plus a warning line when something is missable. Challenge names and objectives come from the mission's own data file; the tactical geography (rooms, items, NPCs) is drawn from the standard Mumbai walkthrough. Anything genuinely random (the Maelstrom's face, alt-start unlocks) is called out rather than invented.

Coins matter: phone booths and the cloth vendor need coins. Bring 3–4 in your loadout; more sit by shop cash registers and in the tailor shop.

Four rules behind the routing. (1) Challenges are permanent — you never lose one by doing runs in order. (2) The Maelstrom's face is random each replay, so any run that kills him identifies him first. (3) You can't kill one target two ways in a single run — save before the kill, reload per variant. (4) Metas (Versatile Assassin, The Helping Hand, The Classics) tick off cumulatively.

All 80 entries are transcribed verbatim from the mission's challenge data file. The green tag on each shows which run earns it.

Mutually exclusive — separated by design

Within a run (save/reload): Vanya's 5 solo deaths (R2); Maelstrom's 3 kills (R3); Rangan's 3 kills (R4); the 4 set pieces (R6); No You Hang Up vs Call Her Maybe (R1); Red Flag vs Hoist the Flag (R3, same flag).

Across runs: Kashmirian alive (R1) vs subdued/killed (R7); taxi exit (R2) vs hideout exit (R7).

Hard prerequisites

Maelstrom photo (random each replay) before any run that kills him: R3, R5, R6, R8.
Tailor + blue cloth before Stand Still. Servant + taster sequence before Tea Time.
Recovered script before the fan kill. Above-floor position for Drop the Mike.
Kashmirian alive for every "help the Kashmirian" challenge (R1 before R7).

Metas (cumulative)

Versatile Assassin = Piano Man + Someone Could Hurt Themselves + Hold My Hair + Straight Shot + Tasteless, Traceless (R2/R5/R7).

The Helping Hand = The Foreman + The Artist + The Kashmirian (R1, or R7 for the last).

The Classics = Silent Assassin + SASO + Sniper Assassin + Suit Only (R5 + R8).

Sourcing

Verified from the game file: every challenge name, category, and objective.

From the standard Mumbai walkthrough: the room-by-room geography, item spots, and NPC roles in each step.

Not fabricated: the Maelstrom's appearance and alt-start mastery unlocks are random/level-gated and are flagged rather than invented; the exact Memoirs tape count and full Chameleon disguise count aren't in the data, so those steps point you to the in-game map/counter.
