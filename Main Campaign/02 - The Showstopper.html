Run-logic validation (simulated step by step)

  • 63 of 65 challenges are assigned to a run. The two left out are Chameleon and Discover Paris, which are exploration passes rather than route steps — see above.
  • Prerequisites precede use. Run 1 takes Helmut's phone before calling Dalia; Run 2 takes the invitation before the two checkpoints that need it; Run 4 takes the speedboat key before the barge; Run 5 takes the security guard's outfit before it is needed for the exit; Run 8 drops the pistol before the frisk.
  • Nothing needed later is destroyed earlier. Every kill branch inside a run sits behind a save, and the branch that is kept is always the last one — Run 1 keeps the fiber wire on both targets so The Personal Touch survives, Run 3 keeps the push into the Seine, Run 7 keeps the on-stage shot.
  • Mutually exclusive kills are separated. Dalia has nine distinct kill challenges and Viktor eleven; no run tries to stack two of them without a reload between.
  • Un-spotted requirements are isolated. Runs 4, 5 and 7 each carry a "can't be spotted" challenge (In Plain Sight, Close Personal Protection, Setting the Stage) and none of them shares a run with another one.
  • Suit-only conflicts are isolated. Run 8 takes no disguise at all and kills with a push, so it never collides with the disguise-heavy runs. Run 9 is allowed disguises because Sniper Assassin does not require the suit.
  • The Classics capstone lands last. Run 8 delivers Silent Assassin, Silent Assassin Suit Only and Suit Only; Run 9 delivers Sniper Assassin and fires the capstone on completion.

Known conflicts, bugs and ordering rules

  • Run 4, sniper bug: fish reports that Viktor's bodyguard can spot you after both targets die even with a suppressed rifle. In Run 4 he shoots the bodyguard to clear it. Do not shoot him in Run 9 — killing a non-target voids Sniper Assassin. Reload instead.
  • Run 4, coconut of Paris: In Plain Sight requires the fireworks to be triggered and both targets sniped within ten seconds and no spotting. All three, or it does not fire.
  • Run 5, order matters: the security guard on the director's-office balcony must be pacified and hidden before you climb to the attic for the magician outfit, because you come back for his clothes afterwards.
  • Run 2, sink timing: Dalia and her personal bodyguard must already be in the meeting room and talking before you overflow the sink, otherwise they investigate it before the CICADA bodyguard does and the whole sequence breaks.
  • Run 8, the frisk: the pistol has to be dropped in the library first. You are frisked on the way back up to the auction room and a found weapon ends the suit-only attempt.
  • Difficulty: the save-and-reload branches assume unlimited manual saves, i.e. Casual. In World of Assassination the Classic challenges are no longer difficulty-tiered, so playing Casual costs nothing.
