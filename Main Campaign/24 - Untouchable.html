Map rules that shape every run

  • No loadout at all. Outside the ICA Facility training missions, this is the only mission in the trilogy with no smuggled items, no agency pickups, and nothing carried in. Every tool below is found on the train.
  • No Mission Stories exist here, so there is no story ordering to protect and no "complete all stories" challenge.
  • No accident-kill challenge exists here. Snow Angel (throwing a guard off the train) is a Feat, not an accident kill.
  • Three endings are mutually exclusive per attempt: poison Edwards (Losing Everything), headshot Edwards (Straight Shot), or inject yourself (A New Father). Save outside his carriage and reload to bank all three.
  • Suit Only and all seven disguise challenges cannot share a run. That is the Run 1 / Run 2 split.
  • If you shoot Edwards you must pull the Emergency Brake in his office to end the mission. Injecting him ends it automatically. Missing this is the most common way people get stuck at the end.
  • Challenges only track online, and progress survives a reload — save-scumming the last carriage is intended play.

Run logic simulation

  • Run 1 — Fuse (step 3) is picked up before the fusebox needs it (step 4). Screwdriver (step 3) before the water tank (step 7). Hammer (step 5) before the three civilians (step 8). No disguise is ever equipped, so Suit Only holds; only subduals, so Silent Assassin holds. Ends via syringe, which is itself the exit — no brake required. Passes.
  • Run 2 — Keycard and coat (1) precede the corridor. Code 1979 and crowbar (2) precede the metal door. Pistol taken at step 3 is required by the bench at step 6 — this was the one real ordering trap and it is now explicit. Valve for the roof hatch (4) is distinct from the container valve (9). Both shortcut rooms are entered from behind before the levers are pulled. Commando Guard camo (10) is taken before the leader's car (11), so the salute script is intact. Office Staff rack (12) is reached before the office cars, and the seventh disguise lives inside them, so Chameleon can only fire after both. Ends with headshot plus brake. Passes.
  • Run 3 — Pistol at step 1 precedes the signal shot at step 2. Snow Angel's dining-car guard is upstream of Edwards and is never removed by an earlier step. Cans can be gathered at any point before their throws. Self-injection is last. Passes.
  • Run 4 — Depends only on Run 2's shortcut unlocks, which persist across runs. Killing everyone cannot lock out anything, because it is the last run. Passes.
  • Mutual exclusions separated: Suit Only (R1) vs all disguises (R2). Losing Everything (R1) vs Straight Shot (R2) vs A New Father (R3/R4). The save recommended at Run 1 step 8 is the single reload point that lets all three endings be banked without replaying the train.
  • No backtracking: the only doubling-back in any run is within a single car (both valve fetches) or the deliberate roof loop that opens the Passenger Car Door from inside — that loop is the only way in, not an inefficiency.

Marked UNVERIFIED

  • Per-challenge XP. Only two are sourced: Untouchable +2,000 XP, The Setup +4,000 XP. Mission total 46,000 XP. The other 23 individual values are not published consistently, so none are listed.
  • NPC names. Arthur Edwards (The Constant) is the only named character on this map. The lab worker, guards, commando leader and office staff are unnamed generics — none invented here, which is why steps identify them by post and clothing instead.
  • Elite Guard outfit naming. Gamepressure calls the outfit hanging in the sleeping guard's compartment a "Providence Guard outfit" and attributes You've Got Some Skills to it; other guides say the disguise comes from helmeted NPCs. Both routes are given.
  • Does killing guards void Silent Assassin? Sources conflict. One wiki summary says killing Providence members gives a bonus rather than a non-target-kill penalty; Gameranx says plainly it instantly fails the check. Run 1 is a no-kill route, so it satisfies either reading.
  • A New Father timing. Wiki says 47 seconds, PowerPyx says one minute.
  • The Setup prerequisite string — "Explosions Runs Loose" (wiki) vs the Codename 47 mission "Plutonium Runs Loose". Unresolved.
  • Got My Boomstick bug. A single 2021 PowerPyx commenter reported shotgun pickups not registering. No second source, and it long predates current patches — historical report, not a live warning.
  • Laboratory / Outdoors disguise restriction. A May 2023 patch preview said Patch 3.150.1 would remove it. Not confirmed shipped by a second source.
  • Patch attribution. The Untouchable challenge was added in patch 3.50 on 27 July 2021 (Season of Lust) and unlocks the ICA19 Goldballer. The Codename 47 pack containing The Setup was also post-launch. Neither is required for the Train Surfing achievement, which predates them.
