What this mission has, and what it doesn't

Your mission file reports disguiseCount: 0 and areaCount: 0. That confirms what the map implies: this is a Sniper Assassin mission and 47 never leaves the perch.

  • Disguise on every step: none. No disguises exist, so there is no Chameleon challenge.
  • Item on every step: the Druzhina 34 ICA Arctic. There is no inventory and no loadout slots — only the rifle and its ammo types.

Mutually exclusive pairs, and where they were split

  • Prison Food vs Shocking Violence. The battery assault on the prisoner is the first thing in Khabko's routine; the meal comes later. Killing him at the assault means he never eats. Shocking Violence sits in Run 3, Prison Food in Run 4.
  • Collapse of the Union vs This is Fine, Foam Party, Shocking Violence. The star drop needs both targets alive and walking out of the main building together, so any earlier target kill makes it impossible. The star is isolated in Run 6.
  • Pink Mist vs Hold Your Fire. Direct opposites — all headshots versus no shots at people. Runs 5 and 6.
  • Pink Mist vs every accident challenge. Accidents, fire, falling lamps and icicles are not headshots, so Run 5 is headshots only.
  • Black Site vs Pink Mist / Hidden Tiger. A dropped lamp kills by accident. Lamps go in Run 1, where no kill rules apply.
  • Tiger Hunter vs Hidden Tiger. Tiger Hunter needs the evacuation running, which sends the Tigers out on randomised escape paths. Controlled body placement is not realistic at the same time, so Tiger Hunter pairs only with Pink Mist in Run 5 and Hidden Tiger sits in the calm Run 4.

Run-by-run logic check

  1. Run 1 — no kills required, so nothing can be locked out. Quiet collectibles are ordered before the gasoline-tank shot, which is the only loud action and the one that spawns rats 3–6. Passes.
  2. Run 2 — flag → clothes → four building fires → riot spread → both targets inside → padlock (fire kill + fifth building) → Tiger into crowd → main gate last. The main gate is deliberately last because opening it early routes the crowd out of the prison and because the crowd is needed for Fusil for Everyone. Passes.
  3. Run 3 — water valve must precede the battery shot, and both must precede everything else because the assault happens in the opening seconds. Reznikov is killed last so the earlier icicle and carried-extinguisher challenges are already banked. Passes.
  4. Run 4 — poison first (routine timer), toilets second (the guard routine fires within seconds of the start), then snow piles and Tigers, which have no deadline. Khabko is not killed at the battery, so nothing conflicts. Passes.
  5. Run 5 — the target headshots are the evacuation trigger, so they must come first by definition. Nothing else is attempted. Passes.
  6. Run 6 — the star needs both targets alive and meeting, so it precedes all environmental kills; fires and explosions would reroute the pair. Passes.

Not part of the 27 — these are trophies

  • Capital Punishment — complete all 27 challenges.
  • Never Knew What Hit Them — finish as Silent Assassin.
  • In a League of Their Own — score above 1,000,000.
  • Fragile Alliance — make Khabko kill Reznikov, then have him try to flee alone.
  • Second Shooter — shoot open locker 137 in the main building's upper-floor left room to reveal a hidden marksman who fires on targets once the alarm goes.
