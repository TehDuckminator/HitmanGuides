    One routing conflict found during run simulation

    Rock the Boat and Abandon Ship! cannot share a run. Rock the Boat only counts bodyguards killed after the evacuation starts, so no bodyguard may die before the trigger. Abandon Ship! only counts main targets killed while escaping, so no main may die before the trigger. Something has to die to start the evacuation, and the documented triggers are exactly those two things — XboxAchievements describes killing the mains sloppily for one and killing a bodyguard sloppily for the other. No third trigger is documented, so they are split into Run 04 and Run 05. This is why the guide has seven runs, not six.

    Known bugs and hard ordering rules

    • ORDERING RULE (verified). If the alarm is raised while Jin Noo lives, he walks to the hostages and executes one — instant mission failure. Any alarm-based run kills him first.
    • ORDERING RULE (verified). Deadweight needs undisturbed patrols. XboxAchievements: shoot nobody before the meeting.
    • ORDERING RULE (verified). Rock the Boat requires zero bodyguard deaths before the evacuation; Abandon Ship! requires zero main-target deaths before it. Separate runs.
    • Death Raft may kill only one of the two. Several Steam guide commenters report this. UNVERIFIED — user reports only
    • Silent Assassin may not register. The Steam guide author reports Hawkeye failing when Re Thak was the last kill, and passing when a bodyguard was last. UNVERIFIED — single anecdote
    • Sniper mastery XP freeze (HITMAN 3 era). A Hitman Forum thread reports Hantu Port mastery bars stalling and rifle unlocks not applying. Affects unlocks, not challenge completion. UNVERIFIED — single report

    Run simulation — what was checked, step by step

    • Coverage. 12 + 5 + 5 + 2 + 1 + 1 + 1 = 27. No challenge appears twice; none is unassigned. Assassination assignments total 13, feats total 14.
    • Prerequisites. No step needs an item, pickup or disguise, because the map has none — 47 has only the Druzhina 34 ICA from a fixed nest. The only "prerequisite" chains are scripted: the crane panel must be opened before any crane step (Runs 01 and 06), and the hostage container must close before the Deadweight meeting can be called.
    • NPCs still alive when needed. Run 01 keeps Jin Noo and Re Thak alive to the end because both office interruptions need them. Run 03 was reordered so Landlubber uses a bodyguard rather than Jin Noo — the file's wording is "a target", so the old dependency on his office trip is gone, and the life-raft meeting is no longer at risk. Run 06 kills nobody until the drop. Run 07 keeps Re Thak alive through the whole escort.
    • Broken scripts. Run 06 forbids all shooting at people so the meeting script survives. Run 07 requires Lhom Kwai to die before the escort begins, or Re Thak never inherits it.
    • Back-and-forth. Each run is grouped by map zone and by the mission clock: crane and containers first (mission start), collectibles during the quiet middle, office events last. Run 03 follows the accident scripts in the order they occur so nothing is revisited.
    • Mutually exclusive pairs, all separated: Clean Bill of Health ↔ Deadweight ↔ In the Spider's Web (three incompatible hostage states); Skullcracker ↔ all seven accident kills; Rock the Boat ↔ Abandon Ship!; Deadweight ↔ Death Raft / Landlubber / Boom Gate.
    • Nothing becomes permanently unobtainable, because challenges bank the instant they register and every run is a fresh start. PSNProfiles notes you can quit a run as soon as a challenge shows completed.
