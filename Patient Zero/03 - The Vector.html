What this mission is not. The Vector is a fixed sniper-nest mission, not a sandbox. Your own mission file confirms it: disguiseCount: 0, areaCount: 0, areas: []. There are no disguises, no Discovery areas, no Feats, no mission stories, no Intelligence, no mastery track, no item slots and one starting location. Every step below says "Disguise: none" because none exist — that is the honest answer, not a gap.

The job

47 works from a sniper nest overlooking the Shadow Client's militia training camp — the Colorado farm from Freedom Fighters. Dr. Bradley Paine has infected four militia members with the Nabazov virus. Because the virus spreads on contact, everything happens at range.

Five targets: Paine plus four infected. The four are drawn fresh each attempt from a pool of 24 candidates, so you identify them every run. Objectives are: eliminate Paine, eliminate the remaining infected patients, locate exit.

The clue system

Diana gives three clues per infected target. Clue #1 is the man's zone or role and always fits more than one person. Clues #2 and #3 are traits or symptoms and arrive in either order. Only after all three does exactly one NPC fit.

Six zones, five NPCs each — four possible infected and one wildcard — and no zone ever holds more than one target at a time. The full 24-man table with hide spots and accident props is in the Target codex tab.

The fourth, unofficial hint. If you wait a long time after the final clue, Diana may add a live positional tell — that the man is taking a phone call, tying his shoelaces or smoking right now. It is the safest confirmation in the mission, and using it forfeits Quicker than the Eye by definition.

Three rules that decide every run

Panic rule. An infected target runs for the exit if he registers two nearby bullet impacts, an explosion, or a found body. If a target actually leaves, the mission fails outright. Paine flees to his car, parked in front of the West Bridge.
Only the infected run. Ordinary militia never flee, so scaring the compound and watching who bolts identifies targets. It also panics the rest, so it is an all-or-nothing play.
Paine identifies them for you. Paine walks a circuit and stops for a check-up with each infected man. That is why every run below kills Paine last — kill him early and you throw away your best identification tool.

Which challenges need you to reach the exit

Four require completion, three pop on the spot. Four challenge descriptions begin "Complete 'The Vector'…" — Silent Assassin, Brain Detail, Where is Everybody? and Unsafe Work Environment. Those need the exit. Environmentalist, Quicker than the Eye and The One That (Almost) Got Away do not use that wording and unlock the moment their condition is met, so those runs can be abandoned as soon as the tile pops. Wording from your mission file; general rule from RARusk's GameFAQs guide Check your challenge tracker the first time rather than taking it on faith.

Loadout and start

One start: the sniper nest, a water tower on the outskirts of the farm, available immediately since there is no mastery. One weapon: the Sieger 300 Advanced, 47's default for this mission. No item slots, no unlocks. Manual saves are unlimited on Casual and Professional; Master gives you one.

UNVERIFIED. Whether the starting suit can be swapped is not confirmed by any source consulted. The opening cinematic shows a Sieger 300 Ghost while gameplay and the weapon's own wiki entry both give the Advanced — treat the Ghost as set dressing.

Two footnotes

Jeff. If Jeff survived The Source and The Author he appears here, walks to an oil barrel, says a prayer, smokes, and burns himself to death with no input from you. Unverified Nothing states whether that affects Silent Assassin. If a clean SA run fails for no visible reason, test this first.

The Scottish demoman. If a target is a demolitions expert Diana sometimes notes he's Scottish — a Team Fortress 2 joke. The mission is a deliberate throwback to St. Petersburg Stakeout.

Mutually exclusive — kept in separate runs.
  • Environmentalist ✕ Unsafe Work Environment — an explosion is not a ballistic kill.
  • Brain Detail ✕ Unsafe Work Environment — an accident kill is not a headshot.
  • Environmentalist ✕ The One That (Almost) Got Away — panicking a man costs deliberate near-misses; Environmentalist forbids missing.
  • Silent Assassin ✕ The One That (Almost) Got Away — a fleeing target is an alerted target and his body drops in the open.
  • Environmentalist ✕ Where is Everybody? — risky rather than impossible. Any target who needs a bell, plate or bottle shot to reach a hide spot costs a sixth bullet.
  • Quicker than the Eye ✕ Environmentalist / Where is Everybody? / Unsafe Work Environment — those three need you to wait for a specific beat; Quicker needs you to shoot early.

Run simulation — step-by-step validation

  • Every challenge is routed exactly once. Run 1 → 1, Run 2 → 2, Run 3 → 2, Run 4 → 1, Run 5 → 1. Total 7, no duplicates, no omissions.
  • No step needs an item or pickup obtained earlier. The only item is the Sieger 300 Advanced, in hand from the first frame. There is nothing to collect, so no run can be broken by a missed pickup.
  • No step needs a disguise. Confirmed by the mission file — the mission has none.
  • No NPC needed later is removed earlier. Paine is the identification tool for the four infected, so every run that must identify targets kills Paine last. Run 1 never kills him at all. This was the one real ordering trap in the mission and all five runs are ordered around it.
  • No scripted event is broken by ordering. There are no mission stories to sequence. The only script is Diana's clue feed, which runs on its own timer and is unaffected by your shots.
  • Save points do not break later objectives. Saves are placed before a shot, never mid-alert. Reloading restores NPC positions and the clue state together.
  • Completion requirements are respected. Runs 2, 3 and 4 end with an explicit "reach the exit" step because their challenges say "Complete 'The Vector'…". Runs 1 and 5 end with "restart" because theirs unlock on the spot.
  • No run sends you back and forth. There is one fixed vantage point, so routing here means shot order — every run takes isolated zones first so that a discovered body panics as few remaining targets as possible.
  • Nothing becomes impossible mid-run. The only irreversible action is killing a target, and in each run the challenge condition is applied to every kill from the first shot onward, so no kill can retroactively spoil the run except by miss or misidentification — both of which are flagged with restart instructions.
  • Not verified: Bradley Paine's hide spot and accident prop. This affects the last step of Runs 3 and 4 only. Both steps carry the flag, a save instruction and a fallback that still banks Silent Assassin.
  • Not verified: individual XP for five of seven challenges. Total confirmed at 19,000.
  • Not verified: whether reloading a save clears a missed shot for Environmentalist. Run 2 tells you to restart instead.
  • Not verified: whether the starting suit can be changed. Loadout cards say "fixed / unverified" rather than naming one.
  • Not verified: whether Jeff's self-inflicted death affects Silent Assassin. Flagged in the briefing.
  • Not verified: any patch that added or changed a challenge here. No source records one; the seven appear original to the 2017 GOTY release.
