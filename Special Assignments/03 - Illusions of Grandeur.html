Read this once before your first run

Basil is the only target on the map, so no two elimination challenges can pop in one uninterrupted timeline. Every run below is built on save → kill → challenge pops → reload → kill differently. Unlocks are banked the instant they fire and survive a reload.

Do not play these on Master. Master allows a single manual save, which breaks the reload loop. Use Casual or Professional.

Run 1 must come before Run 2. Two challenges are meta-challenges that only fire once their components are all done: Versatile Assassin and The Classics. Both complete their final component in Run 2, but only if Run 1 was finished first.

There are no Mission Stories, no Discovery areas and no disguise challenges here — the mission file lists 0 of each. Rangan Tower is sealed and empty, so Dawood Rangan and the Bollywood crew are not on the map.

What changed after the mission file arrived

The uploaded mission JSON is in-game challenge data and outranks every web source. It corrected two things in the previous draft, both of which had been flagged as uncertain rather than asserted:

  • Hold My Hair is not in this mission. The previous draft carried it on the strength of the Hitman Wiki's challenge category index. The mission file has no such challenge, and its version of Versatile Assassin requires only four components — Piano Man, Someone Could Hurt Themselves, Straight Shot, Tasteless Traceless — with no drowning entry. That is consistent: there is no documented drowning kill on Basil anywhere, and now there is no challenge asking for one. Removed.
  • Versatile Assassin is in this mission. The previous draft excluded it to keep Assassination at 9. The mission file lists it as one of the 9, and No Evidence — which the draft had in the Classics — is not present at all; the fifth Classic is the meta-challenge The Classics. Both corrected.

Everything else in the file matched: 16 total, 9 / 1 / 1 / 5, zero disguises, zero areas, areas shared with Chasing a Ghost.

Confirmed bugs and scripting rules

  • Ordering rule (Hitman Wiki walkthrough): let the private-room conversation run out and Basil dismisses 47, reverting the chawl to a trespassing zone. Kill him before it ends and you keep access — which is what makes the suit-only walk-out possible.
  • Suit access oversight (Hitman Wiki): in the starting suit you are allowed inside the chawls, though guard checkpoints still count as trespassing if ignored. Present since HITMAN 2.
  • Explosive knockdown bug (Hitman Forum): a charge placed on the ground in Basil's path only knocked him unconscious while killing bystanders. Do not stage the explosion in the open street.
  • Running-water alert (NamuWiki): during the electrocution setup, the guard outside reacts to the sound of the running sink, so the taser must go into the puddle and fire immediately.
  • Target lockdown (Hitman Wiki): once lockdown triggers Basil retreats either beneath the northern staircase on the bottom floor or upstairs to the Kashmirian's apartment.

Run-logic simulation results

  • Coverage: all 16 challenges assigned, each to exactly one run. No duplicates, no orphans. Verified programmatically against the mission file.
  • Prerequisite order: Versatile Assassin needs Piano Man, Someone Could Hurt Themselves and Tasteless Traceless (all Run 1) plus Straight Shot (Run 2). The Classics needs Silent Assassin, Suit Only and SASO (all Run 1) plus Sniper Assassin (Run 2). Both metas therefore fire in Run 2, and Run 1 is marked as a hard prerequisite in the run header.
  • Item availability: every item used in a step is either in that run's loadout or picked up in an earlier step of the same run. No step reaches for something not yet obtained.
  • NPC availability: no NPC needed later is removed earlier. Basil's bodyguard is pacified only after he is no longer needed. Basil himself is never killed before Wrong Person to Ask has fired, because that feat is banked during the conversation that precedes every kill branch.
  • Scripted events: the volunteer script is re-triggered fresh by each reload. The one script that can break — the conversation timing out — is guarded by a save placed after the feat fires and before any kill.
  • Save points: every reload point returns to a state where all subsequent objectives are still reachable. Run 3's save sits at mission start, before any action, so both of its branches are reachable from it.
  • Backtracking: Runs 1 and 2 never leave the chawl. Run 3 branch B moves from the street to the third-floor window, one short climb. No run crosses the map.
  • Mutual exclusivity: every elimination challenge is separated by an explicit reload, because a single target makes them all mutually exclusive by definition.
