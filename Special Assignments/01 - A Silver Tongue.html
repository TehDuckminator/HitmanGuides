How the save anchors work

Krish dies once per attempt, so most kill challenges can’t share a run. The way round it is save-scumming: a challenge is written to your profile the instant it fires, and reloading never takes it back. Kill him five different ways off the same save and you keep all five.

Amber SAVE HERE steps create an anchor. Blue RELOAD steps send you back to one — both are chipped on the step header so you can see them without expanding.

Anchors used: Run 2 → Save A (area untouched) and Save B (forklift staged) · Run 3 → driver-outfit save and pre-drop save · Runs 1, 4, 5, 6 → insurance saves only, no reload required.

Run logic simulation

Each run was walked step by step against six questions: is anything required that hasn’t been obtained; has an NPC needed later been removed; has a scripted event been broken; has a pickup been skipped; has a prerequisite been missed; is the player being sent back across the map for no reason. Four problems were found in the previous version and fixed:

  • Run 1 — order fault. Here to Serve was placed after manning the Atlantide stand. Taking a new outfit would have cost you the stand. Both are now satisfied by one action: subdue the vendor at the Atlantide stand, take his outfit, then man the stand.
  • Run 1 — wasted trip. The car explosive was planted on a second visit to the Truck Area. It is now planted during the same pass as the faucet, and detonated later from cover.
  • Run 2 — over-staging. Shockingly Pure, the drowning and the explosion need no forklift staging, but were listed after it. The run now uses two save anchors: one before any staging (three attempts) and one after (two attempts), which cuts roughly half the setup work.
  • Run 2 — unsourced dependency. The drowning previously depended on manning the Atlantide stand, which belongs to Run 1. It now uses a loadout emetic, with the stand as a fallback.

The rule that makes all reloading safe: in World of Assassination a challenge is written to your profile the instant it fires. Reloading a save, restarting the mission or quitting never takes back a challenge you have already popped. Every “reload to your save” instruction in this guide relies on that.

Mutual exclusions

  • Every kill-method challenge excludes every other one — Krish dies once per attempt. Crushed Dreams, Nutjob, Oil and Water, Shockingly Pure, It’s Only Water!, Against the Rules, Unquenchable Thirst, Piano Man, Straight Shot and Sniper Assassin each need their own attempt, hence the save anchors.
  • Brokenhearted vs. Against the Rules. Brokenhearted requires the car destroyed and the target alive, then a reaction. Run 2’s car-bomb kill needs the car intact as bait. Never attempt both in one run — they are split into Runs 1 and 2 deliberately.
  • Suit Only / SASO vs. every disguise challenge. Here to Serve, Driving Business, Repping Atlantide, Aggressive Advertising, It’s Only Water! and Crushed Dreams all need a disguise, so none can share a run with Run 5.
  • Atlantide Space Program vs. any rating. The falling debris is documented as likely to kill everyone in the Truck Area. Run 6 stays isolated.
  • Sniper Assassin vs. accidents. The kill must come from the rifle, so it cannot share an attempt with any accident challenge.
