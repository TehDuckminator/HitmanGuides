Run-logic validation (simulated step by step)

  • Every challenge is assigned. 18 of 18 appear in a run. No duplicates: each kill-method challenge sits in exactly one save branch.
  • Prerequisites precede use. The gate key is taken before the gate is opened; the shaman outfit is taken before the blessing; the cook outfit and poison are held before the stew is spiked; the sniper rifle is smuggled in at planning, not found on site.
  • Nothing needed later is destroyed earlier. Run 2 blesses Reddington before poisoning him, because a dead target can't be blessed. Run 1 saves before the first kill, so every later kill branch still has a live target.
  • Mutually exclusive challenges are separated. Reddington is the only target, so only one kill method registers per save state. The six kill-method challenges are split across reload branches, never stacked.
  • Suit-only conflicts are isolated. Run 3 (SASO) takes no disguise at all, so it is kept away from Run 2, which requires two disguises.
  • Save points don't break objectives. Every recommended save is taken while the target is alive, the Black Book is either in hand or still on its table, and no alarm is active — so every branch loaded from it can still finish the mission.
  • No backtracking. Runs 1 and 2 both end at the Shaman's Hut clearing rather than crossing the map twice; Run 3 and Run 4 are single-direction infiltrations.

Corrections to the original brief

  • No Mission Stories exist here, so there is no mandatory story order, no "Hero of" challenge, and no story-script conflicts to route around.
  • No Discovery category and no Chameleon challenge — the in-game data shows zero tracked disguises and zero tracked areas. Disguises still exist and are still used; they just aren't challenge-tracked.
  • No Evidence is not part of The Classics here. It was removed from the set. Do not plan a camera-erasure run.
  • Versatile Assassin is a Colombia-wide challenge, not an Embrace-only one. Its five components can be completed in Three-Headed Serpent instead, in any mix.

Known conflicts and bugs

  • Briefing error, not a bug: Diana says Reddington carries the Black Book at all times. He does not — it is on a table in the Shaman's Hut. Confirmed as a scripting/VO error by the Hitman Wiki.
  • Picking up the Black Book is an illegal action in every disguise, including the shaman and guard outfits. There is no disguise that makes it safe; it must be done unobserved.
  • Alerting Reddington relocates him to the truck outside the forest or into the Shaman's Hut. The hut variant puts his escort on top of the Black Book. This is the single most important ordering rule in the mission.
  • Master difficulty allows only one manual save. The save-and-reload runs below are designed for Casual. No Classics challenge in this mission is difficulty-tiered in World of Assassination, so playing Casual costs you nothing.
  • No mission-specific bug reports were found for Embrace of the Serpent in any source consulted. Reddit and Steam threads about this mission complain about difficulty, not broken scripting.
