Progress is read live from each guide's own checklist and is stored in this browser only. Tick challenges inside a guide — this page updates the moment you come back to it. A file is stamped in its own colour once every challenge in it is done, and each guide has its own reset.

For the totals to add up across guides, all the pages must share one browser storage. Opening them through Start Guides.cmd (http://localhost) guarantees that in every browser; opening the files directly works in Edge and Chrome but not Firefox.

Segment size is that guide's share of all 0 tracked challenges, and every figure here is read from the guides themselves rather than typed in. Files without a link have no guide written yet and are not counted. Route-step counts appear once a guide has been opened at least once.
